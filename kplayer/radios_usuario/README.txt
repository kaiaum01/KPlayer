Coloque nesta pasta arquivos .pls, .asx, .m3u ou .m3u8 de rádios online.
No KPlayer, entre em Rádio Online, selecione Rádio do Usuário com esquerda/
direita e pressione Y para atualizar a lista após adicionar arquivos.
Cada endereço HTTP/HTTPS encontrado aparece como uma estação; arquivos grandes
acima de 64 KiB e outras extensões são ignorados. O nome mostrado é o nome do
arquivo, com número para as entradas seguintes. Transmissões e conectividade
dependem das emissoras. O exemplo Rádio Ilha usa o endereço enviado pelo usuário
e não foi testado no R36S.
