# Controls / Controles — KPlayer v2.1.5 (R36S)

**English:** **B** confirms/opens and **A** goes back/cancels. **SELECT** opens or closes contextual Settings. **START** pauses/resumes active media. Tactile click sounds play on button presses (toggleable under **SELECT → Sons das teclas**). Software volume controls are not used; adjust volume with the console's physical buttons.

**Português:** **B** confirma/abre e **A** volta/cancela. **SELECT** abre ou fecha as Opções contextuais. **START** pausa/retoma a mídia ativa. Cliques táteis sonoros acompanham a navegação (podem ser ligados/desligados em **SELECT → Sons das teclas**). O volume é controlado diretamente pelos botões físicos do console.

Menu flutuante estilo GTA Trainer no canto superior esquerdo: **Cima / Baixo** escolhe a linha (`Tocar/Pausar`, `Próxima Música/Rádio`, `Voltar Música/Rádio`, `Volume`, `Fechar Trainer`), **Esquerda / Direita** ajusta o volume (`10%–100%`) ou troca faixa, **B / START** ativa a opção, **R2 / L2** pula/volta faixa de qualquer linha, **A** ou **L3 + R3** fecha e volta ao jogo |
| **Online Radio / Rádio Online** | Up/down selects station; left/right changes category; B plays/pauses; X favorites; Y refreshes; L1/R1 previous/next station; SELECT opens Radio Options; A returns / Cima/baixo escolhe estação; esquerda/direita muda categoria; B toca/pausa; X favorita; Y atualiza; L1/R1 troca estação; SELECT abre Opções de Rádio; A volta |

| **News / Notícias (NewsData.io + RSS)** | Up/down selects headline or scrolls article body; **B** opens full article reader; **Left/Right** or **X** switches category (`Todas / Urgente / Mundo / Polícia / Entret. / Esportes`); **L1/R1** jumps to previous/next article inside the reader; **Y** refreshes; **A** goes back / Cima/baixo seleciona manchete ou rola a matéria; **B** abre leitura completa; **Esquerda/Direita** ou **X** troca categoria; **L1/R1** anterior/próxima matéria; **Y** atualiza; **A** volta |
| **Placar da Bola (Match List & Details)** | Up/down selects match or scrolls stats; B opens Match Details; left/right or X switches filter (`All / Live / Brazil / Europe`) or detail tab (`Stats / Events / Lineups`); Y refreshes; A returns / Cima/baixo seleciona ou rola; B abre Detalhes; esquerda/direita ou X troca filtro ou aba (`Estatísticas / Eventos / Escalações`); Y atualiza; A volta |
| **Settings / Opções (`SELECT`)** | Contextual to the current screen; General Settings are listed in **alphabetical order** (including **`Áudio em jogos (Teste prévio)`** ON/OFF) with **`[A] Verificar atualizações`** penultimate and **`Sair`** last. Up/down selects; B confirms/toggles; A or SELECT closes / Contextuais à tela atual; Configurações gerais em **ordem alfabética** (incluindo **`Áudio em jogos (Teste prévio)`** Ativado/Desativado), com **`[A] Verificar atualizações`** em penúltimo e **`Sair`** por último. Cima/baixo navega; B confirma/alterna; A ou SELECT fecha |

## GPTOKEYB Profile (`ports/kplayer/kplayer.gptk`)

| GPTOKEYB key | Console button |
| --- | --- |
| Backspace | A |
| Enter | B |
| Space | X |
| M | Y |
| Tab | START |
| F1 | SELECT |
| Arrow keys | D-pad |
| Q / E | L1 / R1 |

Keyboard `Escape` remains an emergency exit for desktop testing and is not mapped to `SELECT`.
