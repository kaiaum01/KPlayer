# Controls / Controles — KPlayer v2.0.0

**English:** B confirms/opens and A goes back/cancels. SELECT opens or closes Settings. START pauses/resumes active media. Software volume controls are not used; adjust volume with the console's physical/system controls.

**Português:** B confirma/abre e A volta/cancela. SELECT abre ou fecha Opções. START pausa/continua a mídia ativa. O aplicativo não altera o volume por software; use os controles físicos/do sistema do console.

| Screen / Tela | Buttons / Botões |
| --- | --- |
| Welcome / Boas-vindas (v2.0.0 Slim) | Up/down switches between Language and Theme color dots; left/right chooses language or live color theme; B saves and continues; Y opens terms / Cima/baixo alterna entre Idioma e bolinhas de cor do Tema; esquerda/direita seleciona idioma ou tema ao vivo; B salva e continua; Y abre termos |
| Terms / Termos | Left/right or up/down changes page; A returns / Direcionais mudam página; A volta |
| Dashboard | D-pad selects card (Music, Video, Files, Online Radio, IPTV, Placar da Bola); B opens; X returns to active player; Y or SELECT opens settings / Direcional escolhe o cartão; B abre; X volta ao player ativo; Y ou SELECT abre opções |
| Music / Música | Y opens Lyrics; X opens Queue and switches Queue/Folder; B pauses in Lyrics or opens/plays list selection; left/right seeks ±10s; L1/R1 changes track; START always pauses / Y abre Letras; X abre Fila e alterna Fila/Pasta; B pausa nas letras ou abre/toca a seleção; esquerda/direita avança ±10s; L1/R1 troca faixa; START sempre pausa |
| Video / Vídeo | B pauses; A stops and returns home; X toggles OSD controls; Y or SELECT settings; left/right seeks ±10s; L1/R1 changes media; L2/R2 seeks ±5s / B pausa; A encerra e volta; X oculta/mostra controles; Y ou SELECT opções; esquerda/direita busca ±10s; L1/R1 troca mídia; L2/R2 busca ±5s |
| Library / Biblioteca | Dedicated folders: `/roms/bgmusic`, `/roms2/bgmusic` (audio only) and `/roms/videos`, `/roms2/videos` (video only). B opens/plays; A returns; left/right switches filter; Y refreshes / Pastas dedicadas: `/roms/bgmusic`, `/roms2/bgmusic` (áudio) e `/roms/videos`, `/roms2/videos` (vídeo). B abre/toca; A volta; esquerda/direita filtra; Y atualiza |
| Online Radio / Rádio Online | Up/down selects station; left/right changes category; B plays/pauses; X favorites/unfavorites; Y refreshes; L1/R1 previous/next station; A returns / Cima/baixo seleciona estação; esquerda/direita muda categoria; B toca/pausa; X favorita/desfavorita; Y atualiza; L1/R1 anterior/próxima; A volta |
| IPTV | Up/down selects item; B watches channel, movie or series; X or left/right switches between Canais (`canais-saimo.pages.dev`) and Filmes e séries (`filmes-saimo.pages.dev`); Y refreshes; A returns / Cima/baixo escolhe item; B assiste canal, filme ou série; X ou esquerda/direita alterna entre Canais e Filmes e séries; Y atualiza; A volta |
| Placar da Bola (Match List) | Up/down selects match; B opens Match Center (Stats, Events, Lineups); left/right or X switches filter (All / Live / Brazil / Europe); Y refreshes scores; A returns / Cima/baixo seleciona jogo; B abre Detalhes (Estatísticas, Eventos, Escalações); esquerda/direita ou X troca filtro (Todos / Ao vivo / Brasil / Europa); Y atualiza placares; A volta |
| Placar da Bola (Match Details) | Left/right or X switches tab (Stats / Events / Lineups); up/down scrolls rows; Y refreshes match data; A returns to list / Esquerda/direita ou X troca aba (Estatísticas / Eventos / Escalações); cima/baixo rola itens; Y atualiza dados da partida; A volta à lista |
| Settings / Opções | Up/down selects; left/right or B changes/opens; X switches section; A, Y or SELECT returns; "Exit KPlayer" closes the app / Cima/baixo seleciona; esquerda/direita ou B altera/abre; X troca seção; A, Y ou SELECT volta; "Sair do KPlayer" fecha o app |

## GPTOKEYB Profile (`ports/kplayer/kplayer.gptk`)

| GPTOKEYB key | Console button |
| --- | --- |
| Backspace | A |
| Enter | B |
| Space | X |
| M | Y |
| Tab | START |
| F1 | SELECT |
| Arrow keys | D-pad |
| Q / E | L1 / R1 |

Keyboard `Escape` remains an emergency exit for desktop testing and is not mapped to `SELECT`.
