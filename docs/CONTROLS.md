# Controls / Controles — KPlayer v2.1.2 (R36S)

**English:** **B** confirms/opens and **A** goes back/cancels. **SELECT** opens or closes contextual Settings. **START** pauses/resumes active media. Tactile click sounds play on button presses (toggleable under **SELECT → Sons das teclas**). Software volume controls are not used; adjust volume with the console's physical buttons.

**Português:** **B** confirma/abre e **A** volta/cancela. **SELECT** abre ou fecha as Opções contextuais. **START** pausa/retoma a mídia ativa. Cliques táteis sonoros acompanham a navegação (podem ser ligados/desligados em **SELECT → Sons das teclas**). O volume é controlado diretamente pelos botões físicos do console.

| Screen / Tela | Buttons / Botões |
| --- | --- |
| **Welcome / Boas-vindas** | Up/down switches between Language and the **14 Theme color dots**; left/right (or L1/R1) picks language or live theme; B saves and continues; Y opens Terms / Cima/baixo alterna entre Idioma e as **14 bolinhas de Tema**; esquerda/direita (ou L1/R1) escolhe idioma ou tema ao vivo; B salva e continua; Y abre os Termos |
| **Commands Tutorial / Tutorial de Comandos** | Shown automatically on first launch (and anytime via `SELECT → Rever comandos`). Press B, A, X, or Y to continue / Exibido na primeira inicialização (e em `SELECT → Rever comandos`). Pressione B, A, X ou Y para continuar |

| **Dashboard / Tela Inicial** | D-pad navigates the 6 animated tiles (**Music & Videos**, Files, Online Radio, IPTV, **News**, Placar da Bola); **B** opens; **X** opens the **Open-Meteo Weather app**; **Y** or **SELECT** opens General Settings / Direcional navega pelos 6 cards animados (**Músicas e Vídeos**, Arquivos, Rádio Online, IPTV, **Notícias**, Placar da Bola); **B** abre; **X** abre o **app de Clima Open-Meteo**; **Y** ou **SELECT** abre Configurações gerais |

| **Music / Música** | **Y** opens Lyrics (`.LRC`); **X** switches Queue / Folder; **B** pauses in Lyrics or plays selected track; left/right seeks ±10s; **L1/R1** previous/next track; **START** pauses; **SELECT** opens Music Options (Equalizer, Speed, Repeat, Shuffle, Favorites, Screensaver, Sleep Timer) / **Y** abre Letras; **X** alterna Fila/Pasta; **B** pausa nas letras ou toca seleção; esquerda/direita avança ±10s; **L1/R1** troca faixa; **START** pausa; **SELECT** abre Opções de Música |
| **Screensaver / Protetor de Tela (10 Visualizers)** | Activates automatically after **30s** idle (default) during Music or Online Radio. **L1 / R1** cycles the **10 audio-reactive visualizers + Auto** live; **X** toggles synced Lyrics overlay; **Y** toggles Clock/Date/Weather overlay; **START** pauses/resumes; any other button exits cleanly / Ativa após **30s** (padrão) em Música ou Rádio. **L1 / R1** troca entre os **10 visualizadores + Automático** ao vivo; **X** liga/desliga Letras; **Y** liga/desliga Relógio/Data/Clima; **START** pausa/retoma; qualquer outra tecla sai |
| **Video / Vídeo** | B pauses; A stops and returns; X toggles OSD controls; SELECT opens Video Options (Speed, Aspect Ratio, Repeat); left/right seeks ±10s; L1/R1 changes media; L2/R2 seeks ±5s / B pausa; A encerra e volta; X oculta/mostra controles; SELECT abre Opções de Vídeo; esquerda/direita busca ±10s; L1/R1 troca mídia; L2/R2 busca ±5s |
| **Library / Biblioteca (`Músicas e Vídeos`)** | Dedicated folders: `/roms/bgmusic`, `/roms2/bgmusic` (audio) and `/roms/videos`, `/roms2/videos` (video). B opens/plays; A returns; left/right switches filter; Y refreshes / B abre/toca; A volta; esquerda/direita muda filtro; Y atualiza |

| **Online Radio / Rádio Online** | Up/down selects station; left/right changes category; B plays/pauses; X favorites; Y refreshes; L1/R1 previous/next station; SELECT opens Radio Options; A returns / Cima/baixo escolhe estação; esquerda/direita muda categoria; B toca/pausa; X favorita; Y atualiza; L1/R1 troca estação; SELECT abre Opções de Rádio; A volta |
| **IPTV (Canais · Filmes · Séries · Usuário)** | Up/down selects category, channel, movie, or episode; B opens/plays (shows live EPG on channels); X or left/right switches tabs; Y refreshes; SELECT opens IPTV Options (Search, Add M3U URL, Refresh); A goes back one level / Cima/baixo escolhe item; B abre/reproduz (com EPG ao vivo nos canais); X ou esquerda/direita alterna abas; Y atualiza; SELECT abre Opções de IPTV (Busca, Adicionar M3U); A volta um nível |
| **News / Notícias (NewsData.io + RSS)** | Up/down selects headline or scrolls article body; **B** opens full article reader; **Left/Right** or **X** switches category (`Todas / Urgente / Mundo / Polícia / Entret. / Esportes`); **L1/R1** jumps to previous/next article inside the reader; **Y** refreshes; **A** goes back / Cima/baixo seleciona manchete ou rola a matéria; **B** abre leitura completa; **Esquerda/Direita** ou **X** troca categoria; **L1/R1** anterior/próxima matéria; **Y** atualiza; **A** volta |
| **Placar da Bola (Match List & Details)** | Up/down selects match or scrolls stats; B opens Match Details; left/right or X switches filter (`All / Live / Brazil / Europe`) or detail tab (`Stats / Events / Lineups`); Y refreshes; A returns / Cima/baixo seleciona ou rola; B abre Detalhes; esquerda/direita ou X troca filtro ou aba (`Estatísticas / Eventos / Escalações`); Y atualiza; A volta |
| **Settings / Opções (`SELECT`)** | Contextual to the current screen; General Settings are listed in **alphabetical order** with **`[A] Verificar atualizações`** penultimate and **`Sair`** last. Up/down selects; B confirms/toggles; A or SELECT closes / Contextuais à tela atual; Configurações gerais em **ordem alfabética**, com **`[A] Verificar atualizações`** em penúltimo e **`Sair`** por último. Cima/baixo navega; B confirma/alterna; A ou SELECT fecha |

## GPTOKEYB Profile (`ports/kplayer/kplayer.gptk`)

| GPTOKEYB key | Console button |
| --- | --- |
| Backspace | A |
| Enter | B |
| Space | X |
| M | Y |
| Tab | START |
| F1 | SELECT |
| Arrow keys | D-pad |
| Q / E | L1 / R1 |

Keyboard `Escape` remains an emergency exit for desktop testing and is not mapped to `SELECT`.
